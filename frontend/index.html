Ce este — și ce nu este

Acesta este un benchmark sintetic de decizie, nu o prognoză reală de cerere pentru România. Adevărul de referință este generat de un simulator cu competiție Huff. Interfața arată predicțiile modelului pe orașe sintetice; valorile absolute în sesiuni pe zi nu trebuie citite ca venit real pentru București.
